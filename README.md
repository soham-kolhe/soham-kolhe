## Projects

### AI Second Brain
[![Repo](https://img.shields.io/badge/🔗_View_Repo-0a0a0a?style=for-the-badge&color=00F0FF)](https://github.com/soham-kolhe/AI-SecondBrain)

**Cut document search from minutes to seconds.** Built a Retrieval-Augmented Generation platform that turns any PDF into a queryable knowledge base — instead of scrolling through 40-page notes, ask a question and get a sourced answer back in context.

- 🔍 Semantic search over Pinecone's vector database — finds relevant passages, not just keyword matches
- 🎴 Auto-generates flashcards and MCQs straight from uploaded material for self-testing
- 📊 Tracks weak topics across sessions so revision targets what actually needs work
- 🔐 JWT-secured, multi-session chat history, containerized with Docker for consistent deploys

`React` `Node.js` `Express.js` `MongoDB` `LangChain` `Pinecone` `Azure OpenAI` `Docker`

### CollabBoard
[![Repo](https://img.shields.io/badge/🔗_View_Repo-0a0a0a?style=for-the-badge&color=FF00AA)](https://github.com/soham-kolhe/CollabBoard) [![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-0a0a0a?style=for-the-badge&color=FF00AA)](https://collabboard-frontend-one.vercel.app)

**Real-time collaboration that doesn't fall apart when someone refreshes.** A multiplayer whiteboard where cursors, strokes, and board state all stay in sync — built the sync layer myself instead of just wiring up a canvas library.

- ⚡ Room-based WebSocket architecture for synchronized multi-user drawing and live cursor tracking
- 🖊️ Tldraw SDK integration with custom board CRUD APIs, from UI through backend to deployment
- 👥 Decoupled client-server architecture (React, TypeScript, Express, Socket.io, MongoDB)
- 🔒 JWT auth, board ownership, and secure room access; MongoDB persistence for seamless session resume

`React` `TypeScript` `Tldraw` `Node.js` `Express.js` `MongoDB` `Socket.io` `JWT`

### Parul MediConnect (Unified HIS)
[![Repo](https://img.shields.io/badge/🔗_View_Repo-0a0a0a?style=for-the-badge&color=B8FF00)](https://github.com/soham-kolhe/Parul_MediConnect)

**One dashboard instead of six disconnected systems.** Hospitals often run OPD, IPD, pharmacy, and billing as separate tools with manual re-entry between them — built a unified platform to close those gaps, as a team of 4 in a hackathon.

- 🏥 360° real-time dashboard tracking patients across OPD and IPD simultaneously
- 🧾 Automated PDF invoice and prescription generation via jsPDF/AutoTable — no manual paperwork
- 🔐 Role-based access control so pharmacy, billing, and clinical staff only see what's relevant
- 🔄 Coordinated data flow across departments instead of siloed record-keeping

`React 19` `Vite` `Node.js` `Express.js` `MongoDB` `jsPDF` `Tailwind CSS`
